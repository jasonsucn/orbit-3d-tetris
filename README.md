# ORBIT · 方块轨道

一场关于秩序与引力的 3D 俄罗斯方块。

## 开始游戏

双击同目录的 **index.html**，使用 Chrome、Edge、Firefox 或 Safari 打开。
游戏为完整独立 HTML，所有图形与声音均由程序实时生成，不依赖网络、CDN、账号或安装包。
如浏览器提示 WebGL 不可用，请在浏览器设置中开启图形 / 硬件加速。

## 两种模式

- **马拉松**：每消除 10 行升级，下降速度随等级增加。
- **40 行竞速**：以最短时间消除 40 行。

## 键盘

| 操作 | 按键 |
| --- | --- |
| 左右移动 | ← → 或 A / D，支持长按 |
| 顺时针旋转 | ↑ / X / W |
| 逆时针旋转 | Z |
| 软降 | ↓ / S |
| 硬降，立即落下 | 空格 |
| 暂存 / 交换 | C / Shift，每个方块可使用一次 |
| 暂停 / 继续 | P / Esc |
| 开始游戏 | Enter |
| 开关交互音效 | M |

触屏可使用下方按钮；棋盘区域也支持左右滑动、轻点旋转、向下快速滑动硬降。

## 体验

- 真正的 WebGL 立体倒角方块、动态光照和后期辉光。
- 落点投影、5 块预览、暂存、7-bag 随机、SRS 墙踢与延迟锁定。
- 消行粒子、冲击波、轻微视差、连击、Back-to-back 与 T-spin 计分。
- 程序合成音效与可选氛围音乐，在设置中调节音量。
- 画面效果、流动视角与落点投影可独立开关；优先遵循系统的减少动态效果偏好。
- 切换标签页或窗口失焦会自动暂停。
- 设置及个人最佳保存在当前浏览器本地；不同浏览器及文件 / HTTP 打开方式的记录相互独立。

## 源码

`index.html` 为最终交付文件，单独复制这一份即可运行。

维护源码：`layout.html`（布局与样式）、`game-core.js`（规则）、`experience.js`（渲染、音效、交互）。
修改源码后运行 `python build.py` 重新生成 `index.html`。
规则验证：`node game-core.test.cjs`。

设计与开发：ORBIT / Blocks in motion.
